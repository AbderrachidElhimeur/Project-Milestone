## Project Milestone 3: Accessible & Designed

1- Accessibility

I used WAVE to check my website for accessibility errors. On the Home and About pages, I added the missing language attribute 
and fixed the text colors to make them easier to read. I also fixed the broken Projects link and the missing form label. 
The Projects page already had the correct language setting, and I kept the colors consistent across all three pages.

2- Visual Design

I used two Gestalt principles: proximity and similarity. I grouped related information together and used the same colors, 
fonts, and button styles throughout the website.

3- Contact Form

I added a contact form to my About page with name, email, and message fields. I used labels, fieldset, and legend to organize 
the form and added error messages for missing or incorrect information. The form opens the user's email app to prepare the message.

4 Testing

I used WAVE to identify accessibility issues and made changes to fix them. I also adjusted the colors to improve contrast. 
I still need to test all three pages again with WAVE and check the final contrast using WebAIM.
